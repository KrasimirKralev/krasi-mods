# model-guard

Chooses the model each Claude Code subagent runs on, by rule. It does nothing until you configure it.

```
/plugin install model-guard --marketplace KrasimirKralev/krasi-mods
```

Settings, recipes and the exact rules for deciding a spawn are in the
[repository README](https://github.com/KrasimirKralev/krasi-mods#readme).
